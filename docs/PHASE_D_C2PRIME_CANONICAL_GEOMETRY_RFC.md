# RFC: C2′ — Canonical (Hamiltonian) Density-Sourced Geometry for the Conservative Branch

**Status: DESIGN ONLY. No implementation, no solver change, no campaign.** Mirror-first if accepted; default-off;
Phase C dissipative default stays byte-identical. Follows from `docs/PHASE_D_C2_CONTRACT_REVIEW.md` (commit 968073e),
which resolved the Codex adjointness escalation: the current C2 geometry term is a Laplace–Beltrami transplant that
is *structurally* quasi-conservative — self-adjoint w.r.t. the Ω³ measure only for frozen Ω, non-canonical for live
Ω(ρ), and discretized in non-divergence form. C2′ is the branch that makes geometry-coupled conservative dynamics
**exactly mass-conserving by construction**.

## 1. Motivation
- The C2 arc (C2.1–C2.3) established: native quasi-solitons exist, transport phenomenology is clean-in-the-continuum
  for pure NLS, and the geometry-ON branch carries a small real algebraic norm flux localized to
  `geometry_covariant_correction` (Codex `DISCRETE_OPERATOR_ADJOINT_FAILURE`, `NO_WEIGHTED_INVARIANT_FOUND`).
- If IRER's conservative sector is to make *quantitative* geometry-coupled transport claims (mobility, binding,
  two-node scattering), the substrate needs exact invariants to measure against. A canonical formulation provides
  mass and energy conservation as *identities*, turning every future norm/energy drift into pure numerics telemetry.
- The physically-motivated route is also the mathematically clean one: derive the flow from the geometric energy
  functional instead of transplanting the curved-space operator.

## 2. The canonical equation
Take the energy functional (conformal metric g_ij = Ω²(ρ)δ_ij at d=3; √g = Ω³, g^ij = Ω⁻²δ^ij):

```
H[ψ] = ∫ [ D·Ω(ρ)·|∇ψ|²  +  V(ρ) ] d³x ,        ρ = |ψ|²,   V′(ρ) = −(a·ρ + s·ρ² + f·ρ³)
```

(the kinetic weight Ω = Ω⁻²·Ω³ is the conformal g^ij√g; V reproduces the existing cubic-quintic-septic nonlinearity).
The canonical flow `i ψ_t = δH/δψ*` is, exactly:

```
i ψ_t = −D ∇·( Ω(ρ) ∇ψ )  +  D·Ω′(ρ)·|∇ψ|²·ψ  −  (a·ρ + s·ρ² + f·ρ³)·ψ          (C2′)
```

Two differences from the current C2 RHS:
1. **Divergence form** `∇·(Ω∇ψ)` replaces the Δ_LB combination `(lap_flat + cov_term)/Ω²`.
2. **A new metric-variation term** `D·Ω′(ρ)|∇ψ|²ψ` (real coefficient × ψ — a density-dependent local potential
   generated by the metric's dependence on ρ). This is the term whose absence makes current C2 non-canonical.

### Exact invariants (continuum, by construction)
- **Mass** M = ∫|ψ|² — Noether charge of the global phase (U(1)); conserved for *any* real H, live Ω included.
- **Energy** H itself — time-translation invariance.
- Momentum is *not* generally conserved (Ω(ρ) breaks Galilean/translation covariance only through ρ, which is
  advected — actually translation invariance holds, so total momentum IS conserved in the continuum; the C2.3
  numerical momentum sink becomes a pure-numerics telemetry channel here too).

### Ω choice
Reuse the existing conformal factor machinery: Ω² = clip((ρ_vac/ρ)^a_coupling), so Ω = (Ω²)^{1/2} and
Ω′(ρ) = d Ω/dρ follows from the existing `d_omega_sq_d_rho` helpers (chain rule; the soft-clip derivative code
already exists in `physics.py` / CuPy kernels). `a_coupling = 0 ⇒ Ω ≡ 1 ⇒ C2′ ≡ pure NLS` — same clean off-switch.

## 3. Discretization: exact discrete mass conservation
- **Divergence form is exactly discretely self-adjoint.** With spectral gradient P (diagonal ik in k-space,
  P† = −P), the operator `A = −P†·diag(Ω)·P = ∇·(Ω∇·)` satisfies A† = A under the *flat* inner product, for any
  positive Ω field, including live Ω(ρ(t)). Then `i ψ_t ⊃ −D·Aψ` conserves Σ|ψ|² identically at the RHS level.
- **The metric-variation term is real·local·ψ** ⇒ pointwise phase rotation ⇒ exactly norm-neutral, like the
  density terms (Codex flux decomposition confirmed those are flux-free to machine precision).
- **Dealiasing:** apply the projection M symmetrically — evolve `ψ_k ← M ψ_k` and evaluate the RHS as `M·N(M·ψ)`;
  `M A M` remains self-adjoint (M diagonal real projection). Note dealiasing still removes mass carried by high-k
  modes it truncates; with a norm-conserving RHS this shows up only through the stepper, not the algebra.
- **Cost:** ∇·(Ω∇ψ) needs 3 forward + 3 inverse FFTs beyond the current stencil (Ω∇ψ products in real space) — same
  order as the existing `n_op` (which already computes 3 gradients); ~1.3–1.5× per-step cost estimate.

## 4. Stepper
The canonical operator has **no useful linear/nonlinear split** (the stiff dispersive part is inside Ω(ρ)∇ψ).
Options, informed by the Codex stepper audit (`ETDRK4_ERROR_CONFIRMED`, RK4 one-step defect ~1.5e5× smaller):
- **(a) RK4 full-RHS (recommended for the diagnostic branch):** simple, and the Codex work already validated an
  RK4 diagnostic harness pattern on CuPy; norm drift then measures stepper error only. CFL: dt ≲ dx²/(π²·D·Ω_max)
  — comparable to current conservative dt requirements.
- **(b) ETDRK4 around a background split** `L_k = −i·D·Ω̄·k²` (Ω̄ = spatial mean, remainder into N): keeps the
  exponential-integrator machinery but reintroduces its dt² norm defect; acceptable for phenomenology with
  dt-ladders, not for invariant-sensitive tests.
- **(c) Later, if warranted:** a norm-exact splitting (Strang: exact phase rotation for local terms + Crank–Nicolson
  for the divergence term) — heavier; only if RK4 dt limits bite.

## 6. What C2′ is NOT
- Not a replacement for C2: C2 (relabeled quasi-conservative) remains the record of what was tested; C2′ is a
  *different substrate* with its own results namespace.
- Not a production change; not a Phase C change; not evidence for IRER — it is the instrument that makes
  geometry-coupled conservative claims falsifiable.
- Not urgent for the current open question (C2.4 local-boost runs geometry-off and is unaffected).

## 7. Open design questions (to settle before implementation)
1. **Kinetic weight exponent:** H_kin = D∫Ω|∇ψ|² uses the conformal g^ij√g = Ω weight at d=3. If IRER intends a
   different power (e.g. Ω² from a different measure convention), the derivation goes through identically with
   Ω→Ω^p — the *structure* (divergence form + metric-variation term) is what matters. Needs a theory-side choice.
2. **Should V(ρ) also carry a √g weight** (∫V(ρ)Ω³)? If yes, additional Ω′-terms appear (same machinery); the
   V13/RFC lineage should decide whether potential energy lives on the curved or flat measure.
3. **Frozen-Ω mode** (Ω from IC, time-independent) as a cheap intermediate diagnostic: exactly conservative under
   BOTH readings, isolates "live metric" effects from "curved metric" effects.
