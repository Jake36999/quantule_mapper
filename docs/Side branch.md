A side branch is defined as a branch that doesnt aim to resolve the questions, or work particularly towards the goals defined in the main branch. But instead, are typically exploratory, robustness testing, or finding which parts of the system an algebraic function defines. 

a branch, should try to have a centralised tracker, with the notes following the pattern of "(Branch name)checking robustness-(typical file name)robustness check A5-Index"
only the file labled index should link back to the main branch, as that provides us the context of when the respective branch was started. The index file, should of course, include an index at the bottom of which tracks the progress, results and chronology of the subsequent documents created. 

This will help us avoid branches, exploratory, or validation seeking from drifting into the main branch without control. It will also keep the obsidian graph view, and any doc tracking canva's respectively clean.
