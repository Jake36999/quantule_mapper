# External Source Registry

Status: provisional Codex source audit for Claude review. This registry records external formulas and dataset leads for external legibility only. It does not change any IRER verdict, does not claim physical correspondence, and does not claim that IRER proves matter, gravity, or unification.

Reliability labels: `primary`, `review`, `secondary`, `weak`.

Verified-status labels:
- `VERIFIED_SOURCE`: source existence and bibliographic identity verified from a publisher, DOI, arXiv, institutional, or repository page.
- `VERIFIED_METADATA_ONLY`: reliable bibliographic metadata found, but formula/full text not fully checked.
- `TO_VERIFY_RELEVANCE`: source exists, but Claude should decide whether it belongs in the IRER comparison.
- `UNVERIFIED`: source not yet verified from a reliable source.

Match levels: `EXACT EQUATION`, `SAME FAMILY`, `CLOSE ANALOGUE`, `SPECULATIVE`, `UNVERIFIED`.
