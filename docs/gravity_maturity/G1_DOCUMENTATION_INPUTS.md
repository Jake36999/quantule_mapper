Different localized clock systems under the same supplied objective temporal field can be calibrated by an independent sparse eigenfrequency contract and JAX GPU time-domain evolution.

## Exact Model

Sparse eigenproblem:

```text
A u = omega^2 M u
A = -div(N_t grad) + N_t(m^2 + V_trap)
M = diag(1/N_t)
```

Time-domain system:

```text
phi_t = N_t Pi
Pi_t  = div(N_t grad phi) - N_t(m^2 + V_trap)phi
```
