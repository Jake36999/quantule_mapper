## Writing Rules

The expanded declaration should match v9's expansive conceptual style without embellishing missing reasoning. Narrative prose may clarify documented reasoning, but must not manufacture intermediate steps, authorial intent, mechanisms, or acceptance. Where the record does not explicitly connect two ideas, the connection is labelled as an inference, proposed synthesis, or unresolved relationship.

Use three voices:

- first person only for existing Jake-authored language or clearly marked draft wording awaiting Jake's approval;
- neutral editorial voice for chronology, evidence qualification, and synthesis;
- explicit attribution for AI-generated equations, mappings, analogies, code, or report language.

New first-person passages are marked as draft wording for Jake review. Silence or continued conversation is not treated as acceptance of an AI formulation.
