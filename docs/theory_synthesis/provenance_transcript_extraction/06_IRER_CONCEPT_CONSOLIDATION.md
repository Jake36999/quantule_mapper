# IRER Concept Consolidation

This document consolidates the theory concepts as they appear across the declaration and transcripts. It records
current meaning, evolution, unresolved tensions, and standard-formalism mappings.

## Concept Status Legend

| status | meaning |
| --- | --- |
| `core_concept` | central IRER terminology from the declaration. |
| `formal_translation` | AI-assisted or later mapping into standard mathematical language. |
| `speculative` | conceptually proposed but not implemented or validated. |
| `partial_analogue` | implemented or tested only through an analogue, not the full IRER claim. |
| `superseded` | historically important but replaced by later project status. |
| `not_quantule_mapper` | relevant to Aletheia/project history but not Quantule Mapper evidence. |

## AIS / PIF

Current meaning:

- A non-temporal or pre-spacetime informational substrate/domain of potential.

Evolution:

- Initially broad metaphysical substrate language.
- Later translated into computational domain/order-parameter-field language.

Standard mapping:

- configuration space;
- field domain;
- lattice/domain carrying an order parameter.

Status:

- `core_concept`, `speculative` as ontology, `partial_analogue` as simulation domain.

Current meaning:

- The substrate tendency toward equilibrium, reduced unresolved potential, or lower informational tension.

Evolution:

- variational principle;
- free-energy minimization;
- relaxation to equilibrium;
- attractor dynamics.

Unresolved tension:

Status:

- `core_concept`, `formal_translation`, `open`.

- `core_concept`, `speculative`, `partial_analogue`.
