## Reading Rules

- AI-heavy files are not false positives. They are mixed-context sources.
- Each passage gets one primary role: original theorising, revision, application method, AI context, non-physics context, or exclude.
- Errors are preserved as historical development artifacts and marked as early, speculative, revised, superseded, null, or contradicted where known.
- Quantule Mapper evidence and current numerical verdicts are referenced only as later status checks, not as the organizing purpose of this pass.
- Cautious language remains binding: no gravity proof, no matter proof, no physical truth claim, and no treating AI-generated formalism as concept origination.
